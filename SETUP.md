# Setup
1. Build/install android/app-debug.apk from GitHub Actions.
2. On phone, enable Notification Access for Phone YTM Companion.
3. Start YouTube Music and play music.
4. Put laptop and phone on the same LAN.
5. On desktop/web/config.js replace PHONE_IP_HERE with the phone IP.
6. Run desktop/start.bat and open http://127.0.0.1:8787.
